# Alakel UI Mobile

This private workspace is the home of the Alakel UI mobile application.

The production website remains at <https://ui.alakel.dev>. React Native documentation and browser previews can use the same domain under a path such as `https://ui.alakel.dev/docs/react-native`.

The workspace currently provides a clean starting point with no mobile framework or native dependencies installed.

## Brand icon

`assets/icon.png` is the canonical mobile icon source shared with the Alakel website identity. When the React Native or Expo application is introduced, reference this asset for development app icons and web favicon configuration.

Before an App Store or Google Play release, derive the required platform-specific icon sizes and opaque backgrounds from the same artwork according to the current store requirements.
